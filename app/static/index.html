Glossary

The glossary is a pronunciation guide: names the assistant would otherwise mangle out loud. Replace this browser's glossary by loading a UTF-8 CSV with one source,target[,transcription] per line — target is how to say it, and the optional transcription is how to spell it on screen. So Suno,スーノ,Suno is said as スーノ and written as Suno. The glossary is stored locally in your browser and sent with each new session — it never affects other users. Changes take effect on the next session (click Start again, or change the voice).
