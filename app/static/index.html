Glossary

Simultaneous mode: The translation model does not use the glossary — it will translate terms in its own way. However, display replacements still work: if the model's output contains a glossary target term, it will be replaced with the transcription column on screen and in captions.

Replace this browser's glossary by loading a UTF-8 CSV with one source,target[,transcription] per line. The optional third column controls how the term appears in the on-screen transcript — useful when you want a katakana pronunciation (target) but a Latin display label (transcription), e.g. Vertex AI,バーテックスエーアイ,Vertex AI. The glossary is stored locally in your browser and sent with each new session — it never affects other users. Changes take effect on the next session (click Start Audio again, or change languages).
