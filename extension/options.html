Live Translator options

Relay backend

The extension sends audio to your Live Translator relay, which holds the Gemini API key. The two Cloud Run regions are separate services with separate session state, so pick one and stay on it for a conversation.

Voice

The prebuilt voice the translation is spoken in. Fixed for the life of a session, so a change applies the next time you press Start.

Microphone

Chrome grants the microphone to the extension as a whole. The engine runs in a background document that cannot show a permission prompt, so if the microphone direction fails, grant it once from here.

Glossary

source,pronunciation,transcript per line. The second column is what the model is told to say; the optional third is what the captions show instead. Applies to the microphone direction and to tab audio with auto-detect off — the simultaneous-translation model takes no glossary.
